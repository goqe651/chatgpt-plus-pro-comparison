## Pro 贵出来的部分：三档分别多了什么

Pro 可以理解为“Plus 的全部能力 + 更高的上限”，定价页给它的标签是“最适合研究和编程”。具体差在下面几处。

### 没有 5 小时限制（目前）

Plus 在滚动的 5 小时窗口内限制消息数，Pro 现阶段没有这个限制。但别理解成“想用多少用多少”：每个模型仍有自己的配额，用完页面会显示重置时间，部分情况还会叠加周限额。

### Pro reasoning：难题上限的差别

Plus 能用高级推理模型，Pro 额外解锁由 GPT-6 Astra 驱动的 Pro reasoning，会给难题投入更多推理计算。写邮件、翻译、摘要这类任务，两档的结果可能很接近；大型代码库重构、多步逻辑推理、长文档交叉核对，差距才真正体现出来。OpenAI 没有公布两者的对比基准，所以“Pro 每个回答都强 10 倍”这种理解不成立。

模型阵容本身也在变动：官方文档显示 GPT-5.5 将于 10 月 14 日从所有订阅档退役；GPT-6.1 Sol 只在 ChatGPT Work 和 Codex 里可用，不进普通聊天。

### dot：Pro 独享的常驻后台代理

dot 是常驻运行的后台代理，Pro 首个 dot 免费附带；Plus 的定价卡片上没有这一项。两个注意点：发布初期欧洲经济区（EEA）、瑞士和英国的用户暂不可用；首月之后的用量条款官方也还没公布。

### Pro 500 的独占项：Astra Ultrafast

只有 Pro 500（以及部分符合条件的 Enterprise/Edu 套餐）能用 Astra Ultrafast：在 Codex 内比标准模式最高快 8 倍的 token 生成速度。代价是它按 8 倍速率消耗订阅额度，用购买的积分则是 6 倍；而且它只存在于 Codex 和 ChatGPT Work，普通聊天里没有。Pro 100 和 Pro 200 就算买积分也解锁不了。顺带一提，受支持模型的 Fast mode 按 2.5 倍速率扣额度，重度使用时这个倍率也得算进去。

Pro 没有这个 5 小时窗口，配额按模型分别计算、到期重置。

## 高成本功能的额度差异

**Codex 和 ChatGPT Work**：两档都支持，而且共享同一个统一算力池——在 Work 里跑一次重研究，会直接吃掉 Codex 的剩余容量。Plus 提供扩展额度，Pro 的会话可以跑得更长，具体长多少官方没有公布。

**Deep Research**：Plus 标注“扩展”，Pro 标注“最高”，具体数字官方未公开。第三方此前的统计口径是 Plus 每月约 10–25 次、Pro 各档 50–250 次的量级；后来档位有过调整，这组数字只能当参考，以账号内实际显示为准。

**图片生成**：Plus 是“更复杂、更准确的图像生成”，Pro 是“无限且更快”——所谓无限仍受防滥用规则约束。一个容易被忽略的细节：图片生成平均会以 3–5 倍的速度消耗 Work/Codex 配额，高频画图的人额度掉得比想象中快。

**语音和视频**：两档都有高级语音，Pro 的额度上限更高；视频生成（Sora）在 Pro 档的生成量和排队优先级也更好，重度创作者是感受最直接的群体。

## 常见问题

**ChatGPT Pro 现在到底是多少钱？**
三档：100、200、500 美元，全部按月订阅，没有年付。

**Pro 的回答质量会好 10 倍吗？**
不会。两档跑的是同一批模型家族，Pro 多出来的是 Pro reasoning、额度和上下文余量。任务越复杂，差距才越明显。

**Plus 或 Pro 包含 API 额度吗？**
不包含，API 单独计费。

**Pro 可以无限使用吗？**
部分功能标注无限，但都受防滥用规则约束，各模型仍有自己的配额，Pro 档也可能叠加周限额。

**可以随时升级或降级吗？**
通常可以。升级立即生效，账单按结算页显示调整；降级在下一个续费周期生效。

**Plus 有年付优惠吗？**
目前没有，Plus 和 Pro 都不支持年付或预付多月。
